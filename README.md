# Personal Dashboard

A personal productivity dashboard built with **HTML, CSS, and JavaScript**.

This project is designed to bring useful everyday tools together in one place through a clean and interactive interface.

> 🚧 **Project Status: Work in Progress**
>
> This dashboard is currently under development. New features, improvements, and refinements will be added over time.

## ✨ Features

- **Dashboard** — A central interface for everyday productivity.
- **Weather** — A dedicated weather page.
- **Notes** — A space for creating and managing notes.
- **Timer** — A dedicated timer page.
- **Calculator** — A built-in calculator.
- **Settings** — A page for dashboard settings.

*Features and functionality may change as development continues.*

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 📁 Project Structure

The project contains separate pages and supporting files for the dashboard, calculator, notes, timer, weather, and settings.

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `Dashboard.html` in your web browser.

Some features may require additional setup or an internet connection.
